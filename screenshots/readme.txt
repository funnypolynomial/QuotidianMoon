Files in this subdir:
convert_eink_dump.py 
  takes a text file parm which is the serial dump
  from QuotidianMoon's eInk display with EINK_DUMP_IMAGE defined
  creats a .png of the same name
  
convert_oled_dump.py 
  takes a text file parm which is the serial dump
  from QuotidianMoon's OLED display with OLED_DUMP_IMAGE defined
  creats a .png of the same name
  
*.txt
  raw dump files, see above

*.png
  converted dump files, see above
